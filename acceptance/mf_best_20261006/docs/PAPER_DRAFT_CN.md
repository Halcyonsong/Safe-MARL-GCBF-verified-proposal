## 摘要

多智能体避障导航在无人机编队、自动驾驶等场景中需要形式化安全保证，但现有学习方法（如 GCBF+、MAPPO-Lag）缺乏可验证性。核心挑战在于：变结构图神经网络（GNN）难以被现有形式化验证工具处理，且部署策略与验证对象常不一致。

本文提出一种验证友好的多智能体控制框架：① **固定维平均场特征**（44 维象限聚合）使策略网络可进入主流验证器；② **残差门控修复**（冻结基座 + 小型修正头）在保持任务性能的同时修复安全违例；③ **反例引导修复循环**（CEGAR）通过采样反例、标注安全动作、重训练、形式化验证的迭代实现渐进式安全增强。

我们在 DoubleIntegrator 八智能体避障任务上实现了**首个有界完备形式化证明**：在声明域 `X_near_plus`（最小威胁距离 d∈[0.14, 0.40]，相对速度 |c|≤0.30）上，两步径向安全性质达到 **PROVEN_FULL**（区间传播 + Marabou 完备验证，耗时 ~2ms）。任务性能：成功率 82.0%、安全率 96.5%、碰撞代价 0.31；控制计算延迟 1.37ms（与 GCBF+ 同量级）。

对比六个基线方法（GCBF+、GCBF、HandCBF、MAPPO-Lag、InforMARL、DeepSet-r2）表明：**现有方法均无同级形式化证书**。我们的工作首次在实际多智能体强化学习任务上达成形式化安全证明，为安全关键应用奠定基础。

**关键词**：多智能体强化学习 · 形式化验证 · 平均场近似 · 控制屏障函数 · 神经网络安全

## 1. 引言

### 1.1 研究背景

多智能体系统（Multi-Agent Systems, MAS）在智能交通、无人机集群、机器人协作等领域展现出巨大应用潜力。然而，在安全关键场景（safety-critical scenarios）中，仅依赖经验评测的性能指标（如碰撞率、成功率）**无法提供充分的安全保证**。当系统部署在真实环境中，未被测试覆盖的边界情况（corner cases）可能导致灾难性后果。

**形式化验证**（Formal Verification）提供了数学严格的安全证明：对于声明的状态空间区域 X，证明性质 P 对 X 内所有状态成立（∀ x ∈ X, P(x)）。近年来，神经网络形式化验证工具（如 Marabou、α-β-CROWN）取得显著进展，但主要应用于图像分类等感知任务，**在多智能体控制领域鲜有突破**。

### 1.2 现有方法的局限

当前多智能体安全控制方法面临以下问题：

1. **基于学习的 CBF 方法**（GCBF/GCBF+）：
   - 用图神经网络学习控制屏障函数（Control Barrier Function, CBF）
   - **变结构问题**：GNN 输入维度随邻居数 k、障碍数 m 动态变化
   - **验证困难**：需按 (k,m) 分桶验证，组合爆炸；现有工具不支持动态拓扑
   - **部署弱化**：训练期用 QP 纠正动作，部署期只跑 GNN Actor（无在线安全过滤器）

2. **约束多目标决策过程**（CMDP）方法（如 MAPPO-Lag）：
   - 通过 Lagrangian 对偶变量软约束安全代价
   - **软约束本质**：违反约束时仅受惩罚，无硬保证
   - **无形式化证书**：经验优化，缺乏可验证性

3. **手工 CBF-QP 方法**（如 HandCBF/DecShareCBF）：
   - 人工设计 barrier 函数，在线求解二次规划（QP）保证安全
   - **延迟高**：在线优化约为神经网络前向的 3-4 倍
   - **泛化弱**：手工设计难以适应复杂场景和变拓扑

4. **形式化验证工具限制**：
   - 主流工具（Marabou、CROWN）支持固定维 MLP/CNN
   - 不支持变长输入、动态图结构、注意力机制
   - 验证复杂度随网络规模指数增长

### 1.3 核心挑战

在多智能体避障任务上实现形式化安全证明，需要解决三个核心挑战：

| 挑战 | 难点 | 现有方法不足 |
|---|---|---|
| **C1: 可验证架构** | 策略网络必须与验证工具兼容 | GNN/注意力 → 变结构，工具不支持 |
| **C2: 安全性质设计** | 找到可验证且实际有效的性质 | 单步性质 → 控制延迟；全局不变集 → 难证 |
| **C3: 任务性能权衡** | 验证友好架构不能损失太多性能 | 手工 CBF → 保守；简化网络 → 欠拟合 |

### 1.4 本文贡献

针对上述挑战，我们提出 **Mean-field 验证友好多智能体控制框架**：

1. **固定维平均场特征架构**（C1）
   - 设计 44 维固定维特征：自车状态（8 维）+ 四象限智能体聚合（20 维）+ 四象限障碍聚合（16 维）
   - 象限聚合保留空间信息，同时实现置换近似不变性
   - MLP512 基座网络 + 小型残差修正头（~22k 参数）
   - **关键突破**：固定维使策略可直接进入 Marabou/CROWN 等主流验证器

2. **残差门控修复框架**（C2 + C3）
   - 部署公式：`a = clip(π_base(x) + g_phys(x) · δ(x))`
   - 冻结高性能基座 `π_base`（蒸馏 GCBF+ GNN Actor）
   - 仅训练轻量修正头 `δ`，物理门控 `g_phys` 在安全区域关闭
   - 保持任务性能的同时修复安全违例

3. **反例引导修复循环**（CEGAR）
   - 迭代流程：采样验证 → 发现反例（CE）→ 安全标签生成 → 修复训练 → 形式化验证
   - `min_intervention` 标签：最小化 `||a_safe - π_base(x)||`，避免过度干预
   - 经验 danger hit 从 5.95%（base）→ 0.47%（r2）

4. **首个有界完备形式化证明**
   - 声明域：`X_near_plus = {x: d∈[0.14,0.40], |c|≤0.30, ...}`（44 维超矩形）
   - 性质：两步径向安全 `d2 = d0 - 0.06·c0 - 0.009·|a|∞ ≥ 0.10`
   - 结果：**PROVEN_FULL**（IBP 整盒证明，~2ms；Marabou 交叉验证 UNSAT ~0.5s）
   - 实际覆盖：79.6% 的危险状态落在已验证盒内

5. **全面实验对比**
   - 任务性能：success 82.0%、safe 96.5%、cost 0.31
   - 基线对比：GCBF+、GCBF、HandCBF、MAPPO-Lag、InforMARL、DeepSet-r2（6 个方法）
   - 多尺度验证：32/64/256 episodes；零样本迁移 N=8/16/32
   - **证书非对称性**：本文方法有 ∀ 证明，基线无同级形式化证书

## 2. 预备知识

### 2.1 多智能体避障任务

**环境**：DoubleIntegrator（双积分器动力学）

| 参数 | 值 | 说明 |
|---|---|---|
| 智能体数 N | 8 | 同质智能体 |
| 区域大小 | 4.0 × 4.0 | 二维平面 |
| 随机障碍 | 4 个 | 矩形障碍物 |
| LiDAR 射线 | 32 条 | 障碍感知 |
| 回合步数 | 256 | 每步 dt=0.03s |
| 通信半径 | 0.50 | 邻居发现范围 |

**动力学**（欧拉积分，与部署一致）：

```
p'(t+dt) = p(t) + v(t) · dt                    (位置更新)
v'(t+dt) = clip(v(t) + a(t)/m · dt, ±0.5)     (速度更新)
```

其中 `m=0.1` 为质量，`dt=0.03` 为时间步长。

**关键观察**：位置 `p'` 仅依赖当前速度 `v`，**不受当前动作 `a` 影响**。动作通过加速度改变速度，需**第二步**才能传播到位置。这是我们采用**两步验证**的物理原因。

**目标**：每个智能体从随机初始位置导航到目标位置，同时避免：
- 智能体间碰撞（距离 < 0.10）
- 与障碍物碰撞（距离 < 0.05）

**评价指标**：
- **Success**：到达目标且无碰撞
- **Safe**：全程无碰撞
- **Finish**：到达目标（可能有碰撞）
- **Cost**：累计碰撞次数

### 2.2 控制屏障函数（CBF）

**传统 CBF**：
对于连续系统 `ẋ = f(x, u)`，barrier 函数 `h: X → ℝ` 满足：
```
h(x) > 0  ⇒  x 安全
ḣ(x, u) + α·h(x) ≥ 0  ⇒  前向不变性
```
其中 `α > 0` 为类指数衰减率。若 `h(x0) > 0` 且前向不变性成立，则 `h(x(t)) > 0, ∀t ≥ 0`。

**CBF-QP 安全滤波器**：
给定标称控制 `u_ref`，求解：
```
min_{u} ||u - u_ref||²
s.t.  ḣ(x, u) + α·h(x) ≥ 0
```
得到安全修正动作 `u_qp`，保证前向不变性。

**GCBF/GCBF+ 方法**：
- 用图神经网络学习 `h` 和 Actor
- GCBF+：训练期用 QP 纠正 `u_ref → u_qp`，Actor 蒸馏该纠正
- **部署弱化**：部署只跑 GNN Actor（无在线 QP），安全依赖网络泛化

**问题**：
1. 学习的 `h` 未被证明是合法 CBF
2. GNN 变结构，难以形式化验证
3. Actor 是 QP 的近似，偏离时无在线纠正

### 2.3 神经网络形式化验证

**问题定义**：
给定神经网络 `NN: ℝⁿ → ℝᵐ`、输入域 `X ⊆ ℝⁿ`、性质 `P`，证明或反驳：
```
∀ x ∈ X,  P(NN(x)) 成立
```

**方法分类**：

| 方法 | 完备性 | 复杂度 | 代表工具 |
|---|---|---|---|
| **区间传播**（IBP） | 不完备 | O(网络大小) | CROWN-IBP |
| **抽象解释** | 不完备 | 低 | AI² |
| **SMT/MILP 求解** | 完备 | 指数 | Marabou, α-β-CROWN |

**Marabou**：
- 基于 Simplex + ReLU 分支定界的完备 SMT 求解器
- 对线性约束 + ReLU 网络**完备可判定**（必然终止）
- 输出：
  - **UNSAT** → 性质成立（proven）
  - **SAT** → 找到反例（violated）
  - **TIMEOUT** → 资源耗尽（unknown）

**当前工具限制**：
- 支持：MLP、CNN（固定维）、ReLU/Tanh
- 不支持：变长输入、动态图、注意力机制
- **本文突破**：通过固定维特征使 GNN 问题可进入主流验证器

## 3. 方法

### 3.1 验证友好架构设计

#### 3.1.1 为什么不直接验证 GNN？

**问题分析**：

传统 GCBF/DeepSet 使用变长实体槽：
```python
输入: graph = {
    ego: [px, py, vx, vy, goal_dx, dy, dvx, dvy],    # 8 维
    neighbors: k × [dx, dy, dvx, dvy, ...],           # k × 7 (变长)
    obstacles: m × [dx, dy, ...],                     # m × 7 (变长)
}
```

**验证挑战**：
1. **输入维度不固定**：k 邻居、m 障碍随时刻变化（k∈[0,7], m∈[0,32]）
2. **必须分桶验证**：需按 (k,m) 组合分别验证，共 8×33=264 种组合
3. **工具不支持**：Marabou 等要求固定维输入
4. **组合爆炸**：每个桶内仍需切分子盒，总复杂度难以承受

#### 3.1.2 固定维平均场特征设计

**核心思想**：用固定维聚合特征替代变长实体槽。

**44 维特征分解**：

| 段 | 维数 | 内容 | 备注 |
|---|---|---|---|
| **Ego** | 8 | `[px, py, vx, vy, goal_dx, dy, dvx, dvy]` | 自车状态与目标 |
| **Agent 四象限** | 20 | 每象限 5 维：`[n, min_d, close_max, close_wmean, inv_ttc_max]` | 邻居聚合 |
| **Obs 四象限** | 16 | 每象限 4 维：`[n, min_d, close_max, inv_ttc_max]` | 障碍聚合 |

**象限聚合策略**：

将 360° 空间划分为 4 个象限（Q0–Q3），每个象限内聚合多个威胁：

```python
for quad in [Q0, Q1, Q2, Q3]:
    n = 该象限内威胁数量
    min_d = min(威胁距离)  if n > 0 else comm_radius
    close_max = max(0, max(相对速度投影))
    close_wmean = 距离加权平均相对速度
    inv_ttc_max = max(close / max(min_d, ε))  # 碰撞时间倒数
```

**关键特性**：
1. **固定维**：无论实际邻居/障碍数，输出永远 44 维
2. **空间保留**：象限划分保留粗粒度空间信息
3. **置换不变近似**：同象限内威胁顺序不影响结果
4. **可验证性**：可直接编码为 44 维超矩形盒 `X ⊆ ℝ⁴⁴`

**与 GNN 对比**：

| 特性 | GNN/DeepSet | Mean-field (本文) |
|---|---|---|
| 输入维度 | 变长（k,m 依赖） | 固定 44 维 |
| 验证域 | 必须分桶 | 统一超矩形 |
| 表达能力 | 强（逐实体编码） | 弱（聚合损失） |
| 任务性能 | 高（GCBF+ 91.4%） | 中等（MF 82.0%） |
| 可验证性 | 难（变结构） | 强（固定维） |

**设计哲学**：牺牲约 10pp 任务性能，换取形式化可验证性。

#### 3.1.3 Base 网络训练

**结构**：
```python
x ∈ ℝ⁴⁴ → Dense(512) → ReLU → Dense(512) → ReLU 
         → Dense(512) → ReLU → Dense(2)
```
- 参数量：约 1.3M
- 输出：`a ∈ ℝ²`（力向量 `[fx, fy]`），**无 tanh**
- 部署：`a_deploy = clip(a, -1, 1)`

**训练方式**：
- **监督蒸馏**：冻结 GCBF+ GNN Actor 跑环境采集 `(x, a_teacher)`
- 损失：danger-weighted MSE，近邻/近障样本权重更高
- 不自行探索或强化学习

**为什么不直接模仿 QP？**
- 试验过直接蒸馏 `u_qp`（QP 纠正后的动作）
- 结果：success 65.6% << Actor 蒸馏 87.1%
- 原因：① QP 标签在危险边界陡峭/不连续；② QP 与两步安全标签几乎正交（MAE≈1.02）

**Base 效果**（v5 step9000）：
- Success: 77.7%（低于 GCBF+ 91.4%，但可用）
- Safe: 80.9%
- Danger hit: 5.95%（这是后续修复的起点）

### 3.2 残差门控修复框架

**动机**：Base 网络任务性能可用，但经验采样发现约 6% 的近危状态两步后碰撞。需在**不破坏 base 性能**前提下修复安全违例。

#### 3.2.1 部署架构

```python
a_deploy(x) = clip(π_base(x) + g_phys(x) · clip(δ(x), ±a_max))
```

**组件**：
- **π_base**：冻结 MLP512（不更新参数）
- **δ(x)**：小型 MLP `44 → 128 → 128 → 2`（~22k 参数，仅 1.7% base 参数量）
- **g_phys(x)**：物理门控，距离威胁远时 `g→0`

**门控设计**：
```python
g_phys(x) = mix * g_dist(x) + (1-mix) * g_ttc(x)

g_dist(x) = relu((d_close - d_min) / (d_open - d_close))
  d_open = 3 × R,  d_close = 1 × R  (R=0.10)

g_ttc(x) = relu((ttc_hi - inv_ttc) / (ttc_hi - ttc_lo))
  inv_ttc = close_max / max(min_d, ε)
```

**特性**：
- 远离威胁（d > 0.30）：`g≈0` → `a≈π_base`（保持 base 性能）
- 接近威胁（d < 0.10）：`g≈1` → 修正激活
- 平滑过渡：ReLU 软切换，避免突变

#### 3.2.2 训练目标

**损失函数**：
```python
L = w_ce · MSE(a_deploy, a_safe)  on CE样本
  + w_idle · MSE(a_deploy, π_base)  on 正常样本
```

**标签生成**：
- **反例（CE）标签 `a_safe`**：通过优化找到让两步后 `d2 ≥ R` 的最近动作
  ```python
  a_safe = argmin ||a - π_base(x)||²
           s.t.  d2(x, a) ≥ R
  ```
  遵循 `min_intervention` 原则，避免过度干预

- **正常轨迹标签**：`a_idle = π_base(x)`，保持基座行为

**训练细节**：
- 仅更新 δ 参数（gate 固定，base 冻结）
- CE 权重 `w_ce=2.5`，idle 权重 `w_idle=1.5`
- 学习率 `lr=8e-5`，训练约 600-1400 步

### 3.3 反例引导修复循环（CEGAR）

**完整流程**：

```
┌─────────────────────────────────────────────┐
│  Step 1: 采样验证                            │
│    在声明域 D 上采样（或 IBP 快速筛）          │
│    执行两步动力学，检查碰撞                    │
├─────────────────────────────────────────────┤
│  Step 2: 反例收集                            │
│    CE = {x ∈ D: TwoStepHit(x, π(x))}       │
│    如果 CE = ∅ → 尝试形式化验证               │
├─────────────────────────────────────────────┤
│  Step 3: 安全标签生成                         │
│    对每个 x ∈ CE，计算 a_safe                │
│    (min_intervention 优化)                   │
├─────────────────────────────────────────────┤
│  Step 4: 修复训练                            │
│    更新 δ 参数，最小化 L_ce + L_idle          │
├─────────────────────────────────────────────┤
│  Step 5: 形式化验证                          │
│    IBP: 整盒 d2_lo ≥ R?                     │
│    Marabou: 对 unknown 子盒完备查询          │
│    输出: PROVEN_FULL / PARTIAL / VIOLATED    │
└─────────────────────────────────────────────┘
         │                           │
         └──── CE 仍存在 ────→ 回 Step 3
         └──── PROVEN ────→ 完成
```

**迭代轮次**（本文实例）：
- **base → r1**：初始 CE 采集，danger hit 5.95% → 1.31%
- **r1 → r2**：残差 warm-start 短修，600 步，danger hit 1.31% → 0.47%

**收敛判据**：
- 经验：4k 采样/桶 无新 CE
- 形式化：L2 near_plus IBP `d2_lo=0.113 ≥ 0.10` → PROVEN_FULL

### 3.4 形式化验证协议

#### 3.4.1 声明与性质

**声明域 X_near_plus**（44 维超矩形）：

| 维族 | 范围 | 物理含义 |
|---|---|---|
| ego v_x, v_y | [-0.5, 0.5] | 自车速度 |
| goal_dx, dy | [-2, 2] | 目标相对位置 |
| **min_d**（8 象限） | **[0.14, 0.40]** | 最近威胁距离 |
| **close_max**（8 象限） | **[-0.30, 0.30]** | 最大相对速度 |
| inv_ttc_max | [0, 8] | 碰撞时间倒数 |
| Q0 agent n | [1, 4] | 强制占用（至少一威胁） |

**性质：两步径向 L2 安全**

```text
定义（占用象限）：
  d0 = min { min_d_q : n_q ≥ 0.5 }
  c0 = max(0, max { close_max_q : n_q ≥ 0.5 })

径向过近似（头对头模型）：
  d2 = d0 - α·c0 - β·|a|∞
  其中 α = n_steps·dt = 2×0.03 = 0.06
       β = (dt²/mass)·n(n-1)/2 = 0.009

性质：
  Safe(x) ⇔ d2(x, π(x)) ≥ R
  其中 R = 0.10 (COLLISION_AA)
```

**Soundness**（正确性保证）：
- **径向 → 平面**：径向安全 ⇒ 同 d0/c0 下平面两步安全（充分条件）
- **特征盒过近似**：轴对齐盒可能包含不可实现组合，证明仍 sound
- **占用感知**：d0/c0 仅统计占用象限（n≥0.5），与特征提取一致

#### 3.4.2 分层验证域

为避免"a=0 已撞"点淹没反例，定义分层可避免带：

| 层 | 模式 | min_d | |close| | d2_lo | 角色 |
|---|---|---|---|---|---|
| L0 | smoke | ~0.25 点邻域 | - | - | 工具链自检 |
| L1 | near | [0.15, 0.35] | ≤0.25 | 0.126 | 基线可避免带 |
| **L2** | **near_plus** | **[0.14, 0.40]** | **≤0.30** | **0.113** | **主验收（本文）** |
| L3 | full | [0.12, 0.50] | ≤0.50 | 0.081 < R | 宽盒附录（预期 violated） |

**物理包络计算**：
```
L2: d2_lo = 0.14 - 0.06×0.30 - 0.009 = 0.113 > 0.10 ✓
L3: d2_lo = 0.12 - 0.06×0.50 - 0.009 = 0.081 < 0.10 ✗
```

L2 物理下界 > R，意味着**任意满足 |a|∞≤1 的策略**在该盒内都径向安全（包络性质）。

#### 3.4.3 验证方法

**IBP（区间传播）**：
```python
给定盒 [lo, hi]，计算：
  d0_lo = min { lo[min_d_q] : hi[n_q] ≥ 0.5 }  or d_empty
  c0_hi = max(0, max { hi[close_max_q] : hi[n_q] ≥ 0.5 })
  a_hi = IBP_forward(MLP, [lo, hi])  # 网络输出上界
  d2_lo = d0_lo - α·c0_hi - β·|a_hi|∞

if d2_lo ≥ R:
  return PROVEN  (整盒安全)
else:
  切分子盒 or 调用 Marabou
```

**Marabou 完备查询**：
```
编码为 SAT 问题：
  输入约束: lo ≤ x ≤ hi
  网络约束: a = MLP(x)  (ReLU 线性化)
  动力学约束: d2 = d0 - α·c0 - β·|a|∞
  违例约束: d2 < R

求解器输出：
  UNSAT → proven (不存在违例)
  SAT → CE (找到反例 x)
  TIMEOUT → unknown
```

**分治策略**：
- 大盒先 IBP，通过则秒级 proven
- IBP unknown 的盒切分：二分沿 d/c 维度
- 小盒（宽度 ≤ 0.08）调 Marabou
- 资源限制：max_splits≈600-800，timeout≈25s/query

### 5.2 验证范围与局限

#### 5.2.1 已证明

✅ **L2 near_plus 盒内两步径向安全**
- 声明域：44 维超矩形，d∈[0.14, 0.40]，|c|≤0.30

#### 5.2.2 未证明（诚实边界）

❌ **无限时域全局安全**
- 原因 1：非前向不变集（状态可能跳出验证盒）
- 原因 2：覆盖率 79.6%（20.4% 状态未验证）
- 原因 3：两步局部性质 ≠ 无限递推

❌ **平面几何完备性**
- 当前：径向过近似（充分非必要）
- SAT 可能虚警（切向运动仍被判 unsafe）
- 更紧性质需平面几何约束（更重）

❌ **网络依赖带（mid-F）**
- d∈[0.125, 0.14) 仍有 CE（附录开放问题）
- 包络界（d≥0.127）可 PROVEN，但基线无 fail 分离

#### 5.2.3 为什么两步而非一步？

**物理原因**：
```
欧拉积分: p'(t+dt) = p(t) + v(t)·dt
         v'(t+dt) = clip(v(t) + a(t)/m·dt)
```
- 第 1 步：位置**不受当前动作影响**（惯性）
- 第 2 步：速度改变才传播到位置（控制生效）

**一步验证问题**：
- 即使 `a` 完美，如果初速度 `v` 已朝威胁 → 第 1 步仍前进
- 无法阻止惯性碰撞

**两步覆盖完整控制周期**：
```
d2 = d0 - α·c0 - β·|a|∞
   = d0 - 0.06·c0 - 0.009·|a|∞  (包含加速度累积)
```

#### 5.2.4 为什么不能递推到全局？

**递推失败原因**：

1. **声明域跳出**（最关键）
   ```
   t=0: x0 ∈ L2, d0=0.20 → 两步后安全 ✓
   t=2: x2 d0=0.13, c0=0.35 → 跳出 L2！未验证
   ```

2. **覆盖率不完整**
   - 79.6% 危险步在盒内
   - 20.4% 在盒外（d<0.14 或 c>0.30）

3. **非前向不变集**
   - 策略未被证明让 `x ∈ X → x' ∈ X`
   - 特征动态流出验证域

**能保证全局安全的方法**：
- **前向不变集证明**：找到 S 使 `x∈S → x'∈S ⊆ Safe`（极难）
- **合法 CBF + 在线 QP**：如 HandCBF（但需在线计算）
- **分层 RTA**：`if x∈X: MF; else: HandCBF`（实用混合）
- **滚动时域验证**：每步检查，全覆盖（需 100% 覆盖率）

### 5.2.5 动力学设计对可验证性的影响

**两步验证的物理根源**：

当前双积分器动力学的控制延迟是两步验证必要性的根本原因：

```python
p'(t+1) = p(t) + v(t) · dt        # 位置仅受当前速度影响
v'(t+1) = clip(v(t) + a(t)/m · dt) # 动作通过加速度改变速度
```

策略输出的力/加速度 `a(t)` 在第一步只能改变速度，需**第二步**才能传播到位置更新。这是牛顿第二定律（F = ma）的直接结果，也是真实物理系统（无人机、机器人、车辆）的本质特性。

**理论探讨：单积分器抽象**：

如果采用单积分器动力学（速度控制模型）：

```python
p'(t+1) = p(t) + v_cmd(t) · dt    # 策略直接输出速度
```

则验证复杂度显著降低：
1. **一步充分**：位置直接受策略控制，一步即可捕获完整控制效果
2. **前向不变性更易证**：相对速度 `c' = v_cmd - v_neighbor` 直接可控，验证 `c' ∈ [-0.30, 0.30]` 变为对策略输出的直接约束
3. **全局安全可能性**：若同时证明 `OneStepSafe(x)` 和 `x' ∈ X`（前向不变），则可归纳推理得到无限时域安全

**工程现实性权衡**：

然而，单积分器假设在工程上存在重大局限：

| 方面 | 问题 | 影响 |
|---|---|---|
| **物理可实现性** | 速度无法瞬时改变（惯性定律）| 违背真实系统物理 |
| **执行器限制** | 加速度受限：`Δv_max = a_max/m·dt ≈ 0.3 m/s` | 大幅转向需 3-4 步 |
| **控制带宽** | 内环跟踪器响应时间 50-200ms | 非瞬时，跨多个周期 |
| **审稿质疑** | "为何不用真实动力学？" | 削弱工程价值 |

真实物理系统（特别是惯性较大的飞行器和地面车辆）无法实现瞬时速度改变。即使存在内环速度控制器（如 PID），其响应也需要多个控制周期，而非一个时间步（dt=0.03s）内完成。

**本文选择的立场**：

我们选择**双积分器**作为主要研究对象，原因：
1. **物理真实性**：与实际部署系统一致
2. **工程可信度**：验证结果可直接指导实际系统设计
3. **贡献清晰性**：首个基于真实动力学的 MARL 形式化证明

单积分器的理论优势（一步验证 + 可能的全局证明）值得在**未来工作**中探索，但需在验证完备性与物理可实现性之间找到新的平衡点，如：
- 分层控制模型：外环策略（低频）+ 内环跟踪器（高频）的联合验证
- 速度跟踪误差界：证明即使有跟踪偏差，系统仍安全
- 多时间尺度验证：验证内环收敛性 + 外环安全性

- 固定维架构 + 完备形式化验证

- 首个 MARL 有界证明

## 7. 结论

### 7.1 总结

本文提出了首个在实际多智能体避障任务上达成形式化安全证明的方法。通过三个核心技术创新：

1. **固定维平均场特征架构**：44 维象限聚合使变结构 GNN 问题可进入主流验证器
2. **残差门控修复框架**：在保持任务性能前提下修复安全违例
3. **反例引导修复循环**：CEGAR 迭代实现渐进式安全增强

我们在 DoubleIntegrator 八智能体避障任务上实现：
- **形式化主验收**：L2 near_plus（d∈[0.14,0.40]）PROVEN_FULL（IBP ~2ms）
- **任务性能**：success 82.0%、safe 96.5%、cost 0.31
- **证书非对称性**：本文方法有 ∀ 证明，六个基线无同级证书
- **实际覆盖**：79.6% 危险状态落在已验证盒内

### 7.2 贡献与意义

**科学贡献**：
- 首次证明多智能体强化学习策略可达到有界完备形式化验证
- 建立固定维特征与验证工具之间的桥梁
- 设计验证友好的残差修复框架

**工程价值**：
- 控制延迟与 GCBF+ 同量级（~1.4ms），远低于在线 QP（~4.7ms）
- 可部署到实时系统（无人机、机器人）
- 提供高置信度安全保证（形式化 + 经验 96.5%）

**开创性**：
- 为安全关键多智能体系统部署奠定基础
- 开辟 MARL 形式化验证新方向
- 证明"可验证性 vs 性能"权衡是可接受的

### 7.3 局限与未来工作

**当前局限**（诚实声明）：
1. **有界非全局**：两步局部证明，非无限时域
2. **覆盖率 79.6%**：20.4% 状态未验证
3. **任务性能权衡**：success 82.0% < GCBF+ 91.4%
4. **径向近似**：充分非必要，可能虚警

**未来方向**：

1. **扩展到无限时域安全证明**
   - **前向不变集搜索**：寻找满足 `x∈S → x'∈S ⊆ Safe` 的最大不变集
   - **分层运行时保障**（RTA）：`if x∈X_verified: MF; else: HandCBF`，结合形式化证明与在线保守控制
   - **滚动时域验证**：每隔 k 步重新验证当前状态在验证域内，提供持续安全保证

2. **动力学与验证的协同设计**（理论探索）
   - **单积分器抽象的验证上限**：探索速度控制模型（§5.2.5 讨论）下一步验证 + 前向不变性的可证明性
   - **分层控制架构验证**：外环策略（低频，MF）+ 内环速度跟踪器（高频，PID）的联合证明，桥接理论优势与物理可实现性
   - **跟踪误差容忍性分析**：证明即使内环存在有界跟踪误差（如 ±5% 速度偏差），外环安全性质仍成立
   - **多时间尺度验证方法**：快速内环收敛性（Lyapunov）+ 慢速外环安全性（本文方法）的组合证明框架
   
   > **工程权衡说明**：尽管单积分器理论上可简化验证（一步充分 + 前向不变性更易证），但其假设脱离真实物理（速度无法瞬时改变）。本文选择双积分器以保证工程可信度，但分层控制验证为未来弥合理论与实践的有前景方向。

3. **平面几何加强性质**
   - 椭圆碰撞包络（更紧但更重）
   - 相对速度矢量分析（非径向过近似）
   - 平面几何完备碰撞条件（去除虚警）

4. **更大规模系统**
   - N > 8 智能体：层次聚合特征（多尺度象限）
   - 3D 环境：八分体（octant）聚合 + 高度维度
   - 异构智能体：不同动力学模型的混合验证

5. **网络依赖带的完备证明**
   - 继续修复 mid-F（d∈[0.125, 0.14)）至无反例
   - 或明确该带为"最优切界"（证明更紧盒必然包含不可避免碰撞点）
   - 与基线方法在同一盒上的形式化对比（需基线也可验证）

6. **部署与运行时保障**
   - 在线状态监控（x ∈ X? 实时检查）
   - 动态切换 MF（高性能）/ HandCBF（保守安全）
   - 定期重验证机制（应对模型漂移）
   - 软件工程：ROS 集成、硬件在环测试

### 7.4 理论贡献与实践价值

**理论层面**：

本文工作揭示了**动力学设计对可验证性的根本影响**。双积分器系统的控制延迟（位置不受当前动作直接影响）是两步验证必要性的物理根源。这一观察指出：

- **验证复杂度非偶然**：源于系统动力学的本质特性（牛顿第二定律）
- **简化模型的验证上限**：单积分器（速度控制）理论上可实现一步验证 + 前向不变性证明 → 全局安全（§5.2.5）
- **工程权衡不可避免**：物理真实性（双积分器）vs 验证简便性（单积分器）的本质张力

这为控制系统设计提供新视角：**可验证性应在动力学建模阶段即纳入考量**，而非事后补救。未来分层控制验证（外环策略 + 内环跟踪器）可能弥合这一鸿沟。

**实践层面**：

形式化安全证明在安全关键 MARL 系统中**不是可选**而是**必需**。本文首次证明：在实际任务上达成形式化验证是**可行的**，尽管需要架构设计权衡（固定维特征 → 约 10pp 性能损失）。这一可行性验证为后续研究奠定基础。

我们希望这项工作激励社区：

- 将可验证性作为网络架构设计的**一等公民**（如本文的固定维设计）
- 开发更强大的验证工具（支持更复杂结构，或降低现有工具的保守性）
- 探索"性能-安全-可验证性"三角形的最优前沿（如分层控制）
- 研究动力学建模与验证需求的协同设计（未来方向 §7.3.2）

**安全不应是事后验证，而应是设计起点。可验证性不应是附加约束，而应是系统架构的内在属性。**
