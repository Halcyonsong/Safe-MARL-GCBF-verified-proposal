## 4. 方法

本节给出验证友好的多智能体控制器综合流程。方法分三阶段：① 固定维平均场（Mean-Field, MF）表示与基座策略训练（§4.1）；② 冻结基座上的物理门控残差修复（§4.2）；③ 几何引导的残差修复（§4.3）与 SafeSet 反推的平面两步形式化验证（§4.4）。整体流程见 Algorithm 1。

**方法要点**：
- **修复与验证分离**：修复由平面几何采样驱动（§4.3）；验证对修复后的部署策略在声明域上查询输入–输出性质（§4.4）。
- **网络依赖验证**：以 SafeSet 几何反推与 Marabou SMT 编码联合约束部署网络输出，避免径向包络的网络无关过近似。
- **有限域可穷尽验证**：按目标速度扰动范围划分 M1–M3 验证档位，并对每个输入子盒执行完备查询；对于预先给定的有限两步声明域，该流程原则上可以穷尽检查全部子盒。

### 4.1 验证友好的固定维控制器表示

#### 4.1.1 从变长图输入到固定维特征

GCBF/GCBF+ 等图策略以变长邻居–障碍实体序列为输入。实体数目随场景变化，导致输入维度不固定；完备验证器（如 Marabou、α-β-CROWN）通常仅支持固定维前馈结构，且需对每种长度组合分别建模，带来组合爆炸与切分复杂度上升。

**设计目标**：构造置换不变的固定维特征，使任意邻居/障碍配置均映射到同一输入空间，从而可直接以固定维盒进入区间界传播（IBP）与 SMT 验证。

#### 4.1.2 象限平均场特征

在 **ego 相对坐标** `(dx,dy)` 下将平面划分为四个轴对齐象限（边界约定与实现一致）：

```text
Q0: dx≥0, dy≥0   Q1: dx<0, dy≥0   Q2: dx<0, dy<0   Q3: dx≥0, dy<0
```

在通信半径内对每个象限做手工统计聚合（置换不变的 set aggregation；下文仍称 MF），得到固定 44 维特征：

```text
x = [ ego(8), agent_Q0..Q3(20), obs_Q0..Q3(16) ]  ∈  ℝ⁴⁴

ego(8)        : [px, py, vx, vy, Δp_goal, Δv_goal]
agent_Qq(5)   : [n, min_d, close_max, close_wmean, inv_ttc]
obs_Qq(4)     : [n, min_d, close_max, inv_ttc]
```

设 `𝒬_q` 为象限 q 内通信范围内的实体集合。对实体 e，记 `d_e=‖p_e−p_ego‖`，`d̂= (p_e−p_ego)/d_e`，接近速度 `close_e = −⟨v_rel, d̂⟩`（`close_e>0` 表示接近）。智能体取 `v_rel = v_e − v_ego`；**静止障碍**取 `v_rel = −v_ego`。聚合量为：

```text
n_q           = |𝒬_q|
min_d_q       = min{ d_e : e ∈ 𝒬_q }            （空集：r_comm）
close_max_q   = max{ close_e : e ∈ 𝒬_q }        （空集：0；实现中再与 0 取 max 用于紧迫度）
close_wmean_q = (Σ_e w_e · close_e) / (Σ_e w_e) （空集：0）
                w_e = exp( −d_e / (0.5 · r_comm) )
inv_ttc_q     = clip( max(close_max_q,0) / max(min_d_q, ε), 0, T_max )  （空集：0）
```

障碍象限省略 `close_wmean`。该表示：① 维度固定；② 同象限内置换不变；③ 可直接作为固定维输入进入验证器。代价是细粒度几何被压缩。形式化证书覆盖的是**声明特征域中的 `x`**（及与之耦合的相对状态关系，见 §4.4.1）。

**冗余维度与 pose 切片。** 静止目标下 `goal_dv ≡ −v`，编码中作等式约束而非自由输入。当前将 `px=py=2.0` 固定为受限输入切片以降低切分维度；植物碰撞几何具有平移结构，但策略输入显式含 `px,py`，故此为声明域选择而非策略平移不变性证明。放宽 pose 会增加求解代价，原则上可沿同一分盒机制继续覆盖。

#### 4.1.3 基座策略训练

基座策略为固定维 MLP：

```text
π_base : ℝ⁴⁴ → ℝ²
```

可通过以下任一方式获得：
1. **从头训练**：直接在固定维特征上用 MAPPO/PPO 训练
2. **教师蒸馏**：从图教师（如 GCBF+）蒸馏到固定维基座

本验收采用蒸馏方式，蒸馏对象取 GCBF+ 的 Actor `π_GNN`，而非 QP 安全滤波器的瞬时输出。QP 在约束激活边界处存在不连续跳变，前馈网络难以拟合；Actor 经软约束训练后已对硬约束作平滑近似，更适于蒸馏。训练完成后冻结 `π_base`，作为后续修复与验证的稳定骨干。

### 4.2 物理门控残差修复

#### 4.2.1 最小干预修正策略

冻结基座在多数状态下已具可用任务性能，但在近威胁区域仍可能违反安全约束。对全网络微调会面临：小规模反例分布偏向危险态导致灾难性遗忘；权重大幅变化使已证子域失效；且绝大部分安全状态并无修正必要。

因此采用**门控残差 + 干预惩罚**设计（设计目标为少改动基座，而非可证明的最优最小干预）：冻结 `π_base`，仅学习轻量残差头 `δ`，并由物理门控 `g_phys` 控制介入强度。部署策略为

```text
a_deploy(x) = clip( π_base(x) + g_phys(x) · clip(δ(x), [−a_max, a_max]) )
```

门控融合归一化距离与碰撞紧迫度。实际实现为：

```text
g_dist(x) = clip( (open_mult − min_d_all(x) / R)
                  / (open_mult − close_mult), 0, 1 )
g_ttc(x)  = clip( inv_ttc_all(x) / inv_ttc_ref, 0, 1 )
g_phys(x) = clip( (1 − mix) · g_dist(x) + mix · g_ttc(x), 0, 1 )
```

其中 `min_d_all`、`inv_ttc_all` 取各象限最近距离与最大紧迫度。推荐 r2 checkpoint 使用 `open_mult=3`、`close_mult=1`、`inv_ttc_ref=5`、`mix=0.5`，且 `R=0.10`。远场低紧迫时 `g` 接近 0，保持基座；近场或高紧迫时残差权重增大；中间区域平滑过渡。`g_phys` 由特征解析给出，训练中不更新。

#### 4.2.2 训练目标与安全标签

残差头由双损失训练，仅更新 `δ`：

```text
L = w_ce · L_ce + w_idle · L_idle

L_ce   = || a_deploy(x_ce) − a_safe(x_ce) ||²     on  x_ce ∈ 𝒟_CE
L_idle = || a_deploy(x_n)  − π_base(x_n)  ||²     on  x_n  ∈ 𝒟_normal
```

`L_ce` 推动危险态修正到安全动作；`L_idle` 约束正常态不过度偏离基座。

对经验违例 `x_ce`，安全标签不是通过连续 QP 求解，而是在 `[-1,1]^2` 的离散动作网格上选择最小干预候选：

```text
a_safe(x_ce) = argmin_{a ∈ G} || a − π_cur(x_ce) ||²
               s.t.      d2(x_ce, a) ≥ R
               G = 11×11 离散动作网格，G ⊂ [−a_max, a_max]²
```

其中平面两步距离 `d2` 的定义见 §4.4。若候选网格中存在安全动作，则选取与当前策略动作距离最小的安全候选；否则选择 clearance 最大的候选作为 fallback（fallback 不保证落入连续 SafeSet，仅服务经验修复）。该标签是离散近似，不是连续可行域上的精确投影。

### 4.3 几何引导的残差修复

修复阶段主要依赖**几何引导的经验采样**，而非以完备验证器作为主反例源。具体流程为：在高风险区域按平面两步碰撞几何采样，用离散动作网格生成安全标签，增量训练残差头；形式化验证在修复收敛后对部署策略独立执行（§4.4）。

#### 4.3.1 平面两步碰撞几何

考虑固定 ego 位置 `(px, py)` 和威胁特征中点的二维 `(dvx, dvy)` 相对速度切面。在离散 DoubleIntegrator 动力学下，每一步先用当前速度更新位置，再用动作更新速度：

```text
v(t+1) = v(t) + a(t) · Δt / m
p(t+1) = p(t) + v(t) · Δt
p(t+2) = p(t) + 2·v(t)·Δt + a(t)·(Δt)²/m
```

由于当前离散更新先用旧速度更新位置、再用动作更新速度，一步位置不含当前 `a(t)`，两步位置才显式含动作影响；故两步是直接验证动作安全影响的最短非平凡窗口。对威胁相对状态 `rel=(dx,dy,dvx,dvy)` 与动作 `a`，两步后相对位置记 `p₂(rel,a)`，并定义

```text
d2(rel, a) := ‖p₂(rel, a)‖₂
```

（他方 coast / 障碍静止，与修复标签一致）。`d2 ≥ R` 即该威胁对上的平面两步 pairwise 距离约束。

#### 4.3.2 高风险区域采样与安全标签生成

在声明域 `X_D`（见 §4.4.1）的平面切面上采样状态，执行当前修复阶段的策略（初始为 `π_base`，后续为当前 residual 策略），并检查 `d2(x, π_cur(x)) < R`。对检测到的违例状态 `x_ce`，在离散动作网格上搜索最小干预安全标签：

```text
a_safe(x_ce) = argmin_{a ∈ G} || a − π_cur(x_ce) ||²
               s.t.      d2(x_ce, a) ≥ R,
               G 为 `[-a_max,a_max]²` 上的 11×11 候选网格
```

若候选网格中存在安全动作，则选择距离当前策略动作最近者；否则选择 clearance 最大的候选。该标签只寻求离散候选中的最小干预，避免过度保守。

#### 4.3.3 增量修复

采样违例 `𝒟_CE` 与正常轨迹样本 `𝒟_normal` 混合训练，仅更新残差 `δ`：

```text
L = w_ce · Σ_{x∈𝒟_CE} || a_deploy(x) − a_safe(x) ||²
  + w_idle · Σ_{x∈𝒟_normal} || a_deploy(x) − π_base(x) ||²
```

冻结 `π_base` 与 `g_phys` 保护任务性能。多轮采样–标注–训练，直至采样集上无显著违例。

#### 4.3.4 修复与验证的关系

修复与验证在流程上分离：

1. **反例来源**：平面几何可高效生成高风险样本；完备 SMT 查询代价显著更高，不宜作为修复主循环的反例引擎。
2. **职责划分**：修复构造可部署策略；验证对该策略在声明域上的输入–输出性质给出形式化结论。
3. **可选回流**：若验证返回 SAT 反例，可并入后续修复轮次，但这不是本流程的主路径。

```text
┌─────────────────────────────────────────┐
│ 1. 平面几何采样（d2 < R 的高风险态） │
└────────────┬────────────────────────────┘
             ↓
          ┌──────┐  无违例
          │ CE?  ├───────────→ 进入验证阶段（§4.4）
          └───┬──┘
              │ 有违例
              ↓
┌─────────────────────────────┐
│ 2. 离散网格生成最小干预 a_safe │
└────────────┬────────────────┘
             ↓
┌─────────────────────────────┐
│ 3. 仅更新 δ（L_ce + L_idle） │
└────────────┬────────────────┘
             │
             └──────→ 返回步骤 1（多轮迭代）
```

### 4.4 SafeSet 反推的网络依赖验证

修复完成后，对声明域进行**平面两步网络依赖形式化验证**。区别于径向包络的网络无关过近似，本方法在 **SafeSet 几何反推 + 部署网络编码**上调用完备 SMT 求解器。  
**证书定级**：验证的是去中心化部署策略在**声明的特征–相对状态关系**上的**局部两步动作安全**（单威胁 pairwise 几何），不是多智能体闭环整局安全。实证结果见 §5。

#### 4.4.1 验证域与 feat–rel 关系

**声明域** `X_D` 是带等式与耦合的 **constrained subdomain**（不是无约束的裸 44 维超矩形），由特征盒 `I_feat` 与相对状态盒 `I_rel` 联合给出：

```text
X_D : {
  pose:  px = py = 2.0  (固定切片)
  I_rel: dx ∈ [0.118, 0.122], dy ∈ [−0.04, 0.04]
         dvx ∈ [−0.30, −0.25], dvy ∈ [−0.05, 0.05]
  threat: 与 I_rel 耦合的象限统计（主声明取特征中点）
  ego_v / goal_xy: 由 vg 档约束；goal_dv ≡ −v（等式）
  R: 0.10
}
```

**关系语义。** `I_rel` 描述**单个**最近威胁的相对位姿–速度；威胁象限特征由 `rel` 几何耦合写入 `I_feat`（其余象限按空象限默认）。验证查询的是该关系上的策略输出，而非“凡映射到同一聚合特征 `x` 的一切原始多实体配置”。多邻居/多障碍的合取、以及全部智能体动作的同时约束，不在当前主证书范围内。

验证按 **M1–M3** 扩展 `vg∈{±0.01,±0.05,±0.10}`。有限域可逐盒穷尽；扩大 pose / threat / 时域需重建盒与充分条件并承担更高代价，但不能由单档结果自动替代。

#### 4.4.2 SafeSet 几何反推

真实安全动作集（对给定 `rel`）：

```text
SafeSet(rel; R) = { a ∈ [−a_max, a_max]² : d2(rel, a) ≥ R }
```

对相对状态盒 `I_rel`，用区间传播在动作模板上二分，得到**充分**动作子集（对盒内一切 `rel` 成立）：

```text
S_suff(I_rel) = { a : a_x ≥ a_min(I_rel), |a_y| ≤ a_max }
```

其中 `a_min(I_rel)` 取使 `min_{rel∈I_rel, |a_y|≤a_max} d2(rel,(a_x,a_y)) ≥ R` 成立的最小 `a_x`（实现见 `safeset_ax_min`）。部署输出已 `clip` 到 `[−a_max,a_max]²`，故在 `a_max=1` 时 `|a_y|≤1` 不增加新的可行约束，**实质网络依赖约束为 `a_x ≥ a_min`**；写出二维模板是为与 clip 后的动作域一致。

**引理（充分性，sketch）。** 若 `a ∈ S_suff(I_rel)`，则对一切 `rel ∈ I_rel` 有 `d2(rel,a) ≥ R`。  
**验证性质（网络依赖）：**

```text
P :  ∀x ∈ I_feat,  π_deploy(x) ∈ S_suff(I_rel)
```

由此推出该 feat–rel 关系上的平面两步 pairwise 安全。它不是“任意动作均安全”的包络检查。

#### 4.4.3 Marabou 完备编码与 M1–M3 扩展

对每个查询盒构造：

```text
1. 输入约束:     x ∈ I_feat（含 goal_dv=−v 等等式）
2. 网络前向:     a = π_deploy(x)（ReLU 展开 + 输出 clip）
3. 充分 SafeSet: a_x ≥ a_min(I_rel)   （|a_y|≤a_max 已由 clip 隐含）
4. 违例查询:     a_x < a_min(I_rel)
```

- **UNSAT** → 该盒 PROVEN  
- **SAT** → 反例（可回流修复）  
- **timeout** → 切分后递归  

| 档位 | vg 半宽 | 含义 |
|------|---------|------|
| M1 | ±0.01 | 微扰动 |
| M2 | ±0.05 | 中等 |
| M3 | ±0.10 | 主引用子域 |

根盒超时后可沿 `vg` 二分再合并。`PROVEN_FULL` 表示该档声明域在充分 SafeSet 编码下**生成的全部子盒均为 UNSAT**（无 SAT / 无遗留 TIMEOUT）。实证见 §5.3。

### Algorithm 1 验证友好控制器综合（修复–验证分离）

```text
Input:  domain X_D, threshold R
Output: deployable π, formal certificate on X_D

// ===== 阶段 1: 基座训练 =====
1:  Build MF encoder; train π_base; freeze π_base

// ===== 阶段 2: 几何引导修复 =====
2:  Initialize residual δ; fix physical gate g_phys
3:  repeat
4:      𝒟_sample ← SamplePlanarStates(X_D); 𝒟_CE ← {x∈𝒟_sample : d2(rel(x),π_cur(x)) < R}
5:      if |𝒟_CE| / |𝒟_sample| < ε_tol then
6:          break   // 经验违例率低于阈值（非形式保证）
7:      for all x ∈ 𝒟_CE do
8:          a_safe(x) ← GatedResidualLabelGrid(x, π_cur, d2, R)
9:      𝒟_normal ← SampleNormalTrajectories(π_base)
10:     Update δ by minimizing w_ce·L_ce + w_idle·L_idle
11: until convergence or max_repair_rounds

// ===== 阶段 3: 形式化验证 =====
12: π_deploy ← gated(π_base, δ, g_phys)
13: for tier in [M1, M2, M3] do   // vg 半宽递增
14:     status ← Verify_Marabou_SafeSet(X_D[tier], π_deploy, R)
15:     record status for tier
16: return π_deploy, certificates for proven tiers
```

**流程要点**：
- **L1**：基座训练（可蒸馏或从头训练）
- **L4**：采样由平面几何驱动，非以验证器为主反例源
- **L12–16**：验证独立于修复，按 M1–M3 分档执行；实证结论见 §5.3
